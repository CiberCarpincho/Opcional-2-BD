Base de Datos Geográfica
Este repositorio contiene recursos para el proyecto de base de datos geográfica.
Archivos 
actividades.sql

Contiene las 7 actividades de base de datos implementadas:

Vista de países con alto PIB per cápita - Países con PIB > $30,000 USD

Vista de ciudades costeras - Ciudades ubicadas junto al mar

Vista de países con múltiples continentes - Países como Rusia y Turquía

Función: calcular crecimiento poblacional anual - Tasa de crecimiento entre dos años

Función: distancia aproximada entre dos ciudades - Cálculo con fórmula Haversine

Procedimiento: insertar una ciudad con validación - Inserción segura con validaciones

Trigger: prevenir población negativa - Evita valores negativos en población

consultas.sql
Contiene consultas SQL especializadas:

Países sin acceso al mar - Países que no tienen costa marítima

Ríos que pasan por más de un país - Ríos internacionales con análisis detallado

Continentes con mayor densidad poblacional - Análisis demográfico por continente
